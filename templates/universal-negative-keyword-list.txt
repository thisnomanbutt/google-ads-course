# UNIVERSAL NEGATIVE KEYWORD LIST
# Companion to Lesson 3.4 — The Negative System & N-Gram Analysis
#
# HOW TO USE
# 1. Read EVERY term before applying. If the business genuinely sells it, remove it.
#    (A training company must NOT block "course". A wholesaler must NOT block "wholesale".)
# 2. Copy the relevant sections into Google Ads:
#    Tools -> Shared library -> Negative keyword lists -> Create list
# 3. Apply the list to your campaigns.
# 4. Remember: negatives do NOT include close variants. Plurals and misspellings
#    must be added separately. This list already includes the common ones.
# 5. Default match type recommendation: PHRASE for multi-word terms, BROAD for single words.
#    Review case by case for anything risky.
#
